# Luagon Bot

Luagon Bot is a free Roblox utility bot made by **L0l kid and friends**. It was inspired by Avis Bot, but it is an independent project. Some commands or features may be similar, different, or unavailable.

## Features

- Roblox account, game, group, avatar, asset, and badge lookups
- ScriptBlox search commands
- Slash commands and prefix commands
- A searchable command directory on the Luagon Bot website

The bot uses Roblox and ScriptBlox APIs for relevant commands. These services are operated by their respective owners.

## Built With

- discord.js
- Lua

## Privacy

- Luagon records command usage counts for security statistics. This applies to slash and prefix commands used in servers or direct messages.
- Command counts are not recorded with the Discord identity of the person who ran the command. These statistics may be shared with the bot's staff. A retention period for these statistics has not been confirmed.
- Luagon does not record full messages or conversations, or keep a log of everything happening in a server. It processes commands to respond to them.
- When `/report <username>` is used, the submitted Roblox username is included in the report and can be seen by the bot's staff.
- A report cannot be cancelled during its two-day review period. After two days, it is automatically deleted and cancelled.
- Commands that look up information may send the relevant input to Roblox or ScriptBlox. Their privacy policies apply to information they receive.
